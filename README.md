# vfm

מנהל קבצים וירטואלי מורחב — היסטוריית גרסאות.

## מבנה המאגר
- `source/` — עץ המקור המלא של הגרסה האחרונה (בלי מפתח החתימה)
- `kod/vfm.txt` — הקוד כקובץ אחד; ההיסטוריה — בהעלאות (commits)
- `notes/` — סיכום כל גרסה
- `apps/` — תוכנות העזר (מדידה, מראה) וגרסאותיהן הישנות
- `docs/` — מסמכי התכנון (עותק מ-26.10.2026; המסמכים החיים בפרויקט ב-claude.ai)
