# 1.26.0 (28.10.2026) — מסך ההרצה האחד, בחירת כמה רשימות, ומהירות

המשתמש (1.25.7): "לא הבנתי — הוא הריץ, ואז מה, חזר לעצמו? ואני צריך להיות נביא מה הוא עשה, ומה נשאר, ומה מחק, ומה הדוח … הוא מתנהל באופן כאוטי." — אחרי סקיצה: "בסדר". ועל הבחירה: "אני רוצה שתביא לי כמה רשימות ולבחור איזה מהם; הוא נותן לי לבחור אחת וזהו."

**מסך ההרצה** (`RunScreen`, `claude/hartzat-pkudot.md`) — ארבעה שלבים זה מתחת לזה, ובראש "שלב X מתוך 4":
1. **מילוי** — המקומות הפתוחים, בתוך המסך (בלי מקומות — "אין מה למלא").
2. **מה יקרה** — "בודק שורה X מתוך Y" עם עצור; אחר כך: ייווצרו · יועתקו/ישתנו · יימחקו · קבצים בכונן (לא נוגע / כמה שורות) · שגיאות · "פרטים — N שורות" (נפתח). "הדמיה" בראש הקובץ — עוצר כאן.
3. **מריץ** — "שורה X מתוך Y · סבב r", פס התקדמות, הזמן, והשורה האחרונה שהסתיימה; עצור (גם בכפתור "חזרה").
4. **סיכום — נשאר על המסך:** נוצרו · הועתקו/השתנו · נמחקו · קבצים בכונן · דולגו · זמן · "הדוח המלא" (נפתח). כפתורים: "פתח את '…'" (הרשימה שנוצרה), יומן (אם יש `מדידה /יומן:`), סגירה.
- פקודות שרק פותחות מסך או רשימה (התפריט ⭐) — כמו קודם, מיד, בלי המסך.

**כמה רשימות:** מקום ששמו מתחיל ב"רשימות" אחרי `ידנית` — "בחירה…" מביא את כל הרשימות הידניות (בכל העומק, מוזחות) ובראש "★ כל מה שבבית", עם סימון של כמה. השורה מוכפלת לכל רשימה שנבחרה. בבדיקת העומס: `<רשימות>` — מה להעתיק; `<רשימה-חדשה>` — לאן. `ידנית "*"` כמקור — כל מה שבבית.
