# 1.28.0 (01.11.2026) — עורך הפקודות: בלי קובץ, טופס לפי בקשה, ו"בדיקה" רק כשמבקשים

המשתמש: "נמשיך פה התיקונים בעורך הפקודות. א. תכין דרך להגיע לעורך הפקודות בלי קובץ מסוים — או בפקודה 'פתח עורך פקודות' או בדרך אחרת. ב. את הטופס לעריכת הפקודות תעביר לאופציה — רק כאשר אבקש אותו, שלא יופיע כל הזמן. ג. את הבדיקות שהוספת לאחרונה תשים באופציה בפקודה גם כן — קובץ שירצה יריץ את הבדיקות האלה; אין צורך שכל פקודה תעבור את המבחן הזה תמיד."

**א. עורך בלי קובץ**
- בתפריט הפקודות ⭐ — "✎ עורך הפקודות"; ובפקודה: `פתח עורך פקודות` (או `פתח מסך עורך פקודות`).
- נפתח עורך ריק ("פקודה חדשה — עוד לא נשמרה"). בשמירה או בהרצה — נשאל שם; הקובץ נשמר ב"שלי" (הקיצורים), והעורך ממשיך איתו.

**ב. הטופס — רק כשמבקשים**
- בברירת המחדל העורך מציג רק את הקובץ (והכפתורים: שמירה, הרצה, ☰ טופס, ★ נפוצות, ושורת העזר שלמטה).
- "☰ טופס" — מציג את החיפוש, התפריט והפרמטרים; "✕ טופס" — מסתיר. הבחירה נזכרת לפעם הבאה.
- ★ נפוצות — פותח את הטופס לבד (שם הן מוצגות).

**ג. "בדיקה" — רק לקובץ שמבקש**
- שורת כותרת חדשה: `בדיקה`. קובץ שיש בו אותה — רץ במסך ההרצה, בשלבים (מילוי ← מה יקרה ← אישור ← מריץ ← סיכום, עם הניקוי).
- **בלי השורה — הקובץ רץ מיד**, בלי תצוגה מקדימה ובלי אישור. מקומות פתוחים עדיין נשאלים; דוח מוצג רק כשמשהו לא הלך חלק, כשיש הודעה (ECHO) או `מדידה`; אחרת — הודעה קצרה.
- מחיקות (`DEL`, `RD`) הולכות תמיד לסל — גם בלי אישור, אפשר לשחזר.
- "בדיקת עומס" בנפוצות — עם `בדיקה` בראש. בעורך: "בדיקה" בתפריט "עוד פקודות" (נכנסת בראש הקובץ).

צמתים בעץ: 6.2–6.3. `classes.dex` **1000848**; קובץ ההתקנה **473193**. 2,112 בדיקות.

**לבדוק במכשיר:** ⭐ ← "✎ עורך הפקודות" — עורך ריק, בלי טופס; ☰ טופס — מופיע ונעלם; כתיבת שורה ← הרצה ← נשאל שם ← רץ מיד. קובץ עם `בדיקה` בראש — מסך ההרצה.
